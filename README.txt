MANIKANTAN & SARANYA — WEDDING WEBSITE
======================================

PREMIUM TEMPLE-DOOR VERSION
- Full carved Kerala temple entrance is shown from top to bottom.
- The two wooden leaves are separated from the carved frame and open on realistic 3D hinges.
- Lighting, shadows, door thickness, warm sanctum glow and camera movement are synchronized with the opening.
- The animation respects reduced-motion accessibility settings.


WEDDING SONG
- The uploaded “Kalyana Kacheri” MP3 is included in assets/kalyana-kacheri.mp3.
- It starts from the beginning when the guest taps “Open the Invitation”.
- It continues throughout the website and loops if the guest remains longer than the song.
- The floating music button pauses or resumes the song.
- Browsers require the first tap before sound can begin.

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or Safari.
3. Tap “Open the Invitation” to start the temple-door animation and the wedding song.
4. The song continues throughout the website and loops when it reaches the end. Use the floating music button to pause or resume it.

UPDATING YOUR EXISTING GITHUB PAGES WEBSITE
1. Extract this ZIP.
2. In your GitHub repository, replace the old website files with every file and folder from this package.
3. Commit the changes to the main branch.
4. Wait about 1–3 minutes for GitHub Pages to deploy.
5. Open your website and perform a hard refresh: Ctrl+Shift+R on Windows/Linux, or Cmd+Shift+R on Mac.

FREE HOSTING — NETLIFY DROP (EASIEST)
1. Extract the ZIP.
2. Open https://app.netlify.com/drop in your browser.
3. Drag the entire “manikantan-saranya-wedding-invite” folder onto the page.
4. Netlify gives you a public website link. You can change its site name in Site configuration.

FREE HOSTING — GITHUB PAGES
1. Create a free GitHub account and a new public repository.
2. Upload every file and folder from this package to the repository root.
3. Open Settings > Pages.
4. Under “Build and deployment”, select “Deploy from a branch”, choose main / root, and save.

IMPORTANT FILES
- index.html: website content and the opening-door structure
- styles.css: colours, Kerala mural styling and 3D hinged-door animation
- script.js: opening timing, song playback, countdown, sharing and WhatsApp RSVP
- assets/temple-door-frame.webp: fixed carved temple frame with an open portal
- assets/temple-door-leaf-left.webp: animated left wooden door leaf
- assets/temple-door-leaf-right.webp: animated right wooden door leaf
- assets/temple-door-frame.webp and temple-door-leaf-*.webp: carved entrance and animated door leaves
- assets/kalyana-kacheri.mp3: the user-provided wedding song
- assets/save-the-date.png: downloadable save-the-date card
- calendar/: calendar event files
